\textbf{[0.8]} 已知双曲线 $C: \frac{x^2}{3} - y^2 = 1$，若直线 $l$ 的倾斜角为 $60^{\circ}$，且与双曲线 $C$ 的右支交于 $M, N$ 两点，与 $x$ 轴交于点 $P$，若 $|MN| = \frac{\sqrt{3}}{2}$，则点 $P$ 的坐标为

\vspace{0.2cm}\par\noindent{\color{red}\textbf{【答案】} $(\sqrt{3}, 0)$}
\par\noindent{\color{blue}\textbf{【解析】} 双曲线 $C: \frac{x^2}{3} - y^2 = 1$。

直线 $l$ 的倾斜角为 $60^{\circ}$，则直线 $l$ 的斜率为 $k = \tan 60^{\circ} = \sqrt{3}$。

设直线 $l$ 的方程为 $y = \sqrt{3}x + m$。

将 $y = \sqrt{3}x + m$ 代入双曲线方程 $\frac{x^2}{3} - y^2 = 1$，得：

$\frac{x^2}{3} - (\sqrt{3}x + m)^2 = 1$

$x^2 - 3(3x^2 + 2\sqrt{3}mx + m^2) = 3$

$x^2 - 9x^2 - 6\sqrt{3}mx - 3m^2 = 3$

$-8x^2 - 6\sqrt{3}mx - 3m^2 - 3 = 0$

$8x^2 + 6\sqrt{3}mx + 3m^2 + 3 = 0$ 

设 $M(x_1, y_1), N(x_2, y_2)$ 是直线 $l$ 与双曲线的交点，则 $x_1, x_2$ 是上述方程的两个根。

判别式 $\Delta = (6\sqrt{3}m)^2 - 4(8)(3m^2 + 3)$ 

$= 108m^2 - 96m^2 - 96$ 

$= 12m^2 - 96$ 

由于直线 $l$ 与双曲线有交点，所以 $\Delta > 0$，即 $12m^2 - 96 > 0$，解得 $m^2 > 8$，所以 $m > 2\sqrt{2}$ 或 $m < -2\sqrt{2}$。

由韦达定理，有 $x_1 + x_2 = -\frac{6\sqrt{3}m}{8} = -\frac{3\sqrt{3}m}{4}$ 和 $x_1 \cdot x_2 = \frac{3m^2 + 3}{8}$。

由于直线 $l$ 与双曲线 $C$ 的右支交于 $M, N$ 两点，所以 $x_1 > 0, x_2 > 0$。

因此 $x_1 + x_2 > 0$ 且 $x_1 \cdot x_2 > 0$。

因为 $x_1 \cdot x_2 = \frac{3m^2 + 3}{8}$，且 $m^2 \ge 0$，所以 $3m^2 + 3 > 0$，即 $x_1 \cdot x_2 > 0$ 恒成立。

因为 $x_1 + x_2 = -\frac{3\sqrt{3}m}{4} > 0$，所以 $m < 0$。

综合 $m > 2\sqrt{2}$ 或 $m < -2\sqrt{2}$ 和 $m < 0$，可得 $m < -2\sqrt{2}$。

弦长 $|MN|$ 的计算公式为 $|MN| = \sqrt{1+k^2}|x_1-x_2|$。

$|MN| = \sqrt{1+(\sqrt{3})^2}|x_1-x_2| = \sqrt{1+3}|x_1-x_2| = 2|x_1-x_2|$。

其中 $|x_1-x_2| = \frac{\sqrt{\Delta}}{|A|} = \frac{\sqrt{12m^2-96}}{8}$。

所以 $|MN| = 2 \cdot \frac{\sqrt{12m^2-96}}{8} = \frac{\sqrt{12m^2-96}}{4} = \frac{\sqrt{4(3m^2-24)}}{4} = \frac{2\sqrt{3m^2-24}}{4} = \frac{\sqrt{3m^2-24}}{2}$。

已知 $|MN| = \frac{\sqrt{3}}{2}$。

所以 $\frac{\sqrt{3m^2-24}}{2} = \frac{\sqrt{3}}{2}$。

$\sqrt{3m^2-24} = \sqrt{3}$ 

$3m^2 - 24 = 3$ 

$3m^2 = 27$ 

$m^2 = 9$ 

$m = \pm 3$。

结合条件 $m < -2\sqrt{2}$ (因为 $-2\sqrt{2} \approx -2.828$)，所以 $m = -3$ (舍去 $m=3$)。

将 $m = -3$ 代入直线 $l$ 的方程 $y = \sqrt{3}x + m$，得 $y = \sqrt{3}x - 3$。

点 $P$ 是直线 $l$ 与 $x$ 轴的交点，令 $y=0$，得 $0 = \sqrt{3}x - 3$。

$\sqrt{3}x = 3$ 

$x = \frac{3}{\sqrt{3}} = \sqrt{3}$。

所以点 $P$ 的坐标为 $(\sqrt{3}, 0)$。}
